# Footmen Frenzy · 四兄弟纪念版 — 项目计划

> 基于经典 Footmen Frenzy 5.5.3W 改造的四人专属纪念地图，目标客户端：魔兽争霸 3 v1.27。
> 本文档是唯一权威计划，每次迭代后更新「迭代记录」。

## 一、目标

四个人（路志鹏、路志远、路鹏飞、方超）的专属 footman 地图：

1. 四个专属英雄，以四人命名，各自带「回忆技能」
2. 电脑位 AI：人不齐时 AI 顶替（控制英雄、拉兵、自动升级）
3. 只在 1.27 客户端可玩（单机、局域网均可），单文件 `.w3x`

## 二、底图与版本

- **底图**：Footmen Frenzy v5.5.3W（作者 miRaculix，基于 Windaleblizard 的 FF 5.4 SD）
- **来源**：wc3maps.com map/41，432KB，带 FF 系列祖传「OP」加密壳（VxOP 头水印）
- **壳已破解**：`unprot.py` 可完整提取全部 31 个内部文件

## 三、四英雄与回忆技能（v1 设计）

实现方式：在 FF 现有英雄池中选 4 个原型换名（换名=改 w3u 名字字段+中文 wts），
每个英雄替换/新增一个「回忆技能」。技能一律用 `ANcl`(Channel) + war3map.j 触发器实现，
不依赖新引擎特性。

|---|---|---|---|---|---|

| 方超 | 智力法师 | **审判** | 指向敌方单位：正义之锤落下，伤害+眩晕（风暴之锤改皮改名） | 「公平正义，迟到但不到」 | 已定 |
| 路志远 | 力量坦克 | **离家出走** | 隐身+加速走脱（风步行改皮改名），下一击附带额外伤害 | 「这个家呆不下去了！」 | 已定 |
| 路志鹏 | 治疗/辅助 | —— | —— | —— | **等素材**，先保留原型技能 |

## 四、AI 设计（电脑位顶替）

FF 没有基地运营（兵是脚本自动刷的），所以 AI = 触发器层，开局扫描
`GetPlayerController(p) == MAP_CONTROL_COMPUTER` 的座位挂 AI：

1. **英雄**：开局自动去酒馆选英雄 → 自动升级技能 → 跟团推线
2. **拉兵**：低血量小兵自动后撤（FF 兵海里拉扯保存战力）
3. **自动升级**：定时买 FF 的兵种升级/基地升级（对应「升级基地」需求）
4. **回撤**：残血英雄撤回基地，脱离战斗再回线

参数（CD、血线阈值、推进目标点）全部集中在脚本头部的 CONFIG 区，方便调。

## 五、技术管线（已验证的部分打 ✓）

```
base/Footmen_Frenzy_v5.5.3W.w3x          # 带壳原版
   │  unprot.py   （OP壳提取 ✓）
   ▼
base/ff553_extract/*.j|w3u|w3a|...       # 明文内部文件
   │  build.py    （改造 + 手术式重打包）
   ▼
dist/FF_4Brothers_vX.Y.w3x               # 1.27 可玩的单文件地图
```

**手术式重打包**（关键设计）：不重建整个 MPQ，而是在原档上做手术——
未知名字的自定义模型/贴图（MDLX/TGA，原路径不可知）原样保留其加密数据块和哈希表项；
14 个已知标准文件 + 单位表/路径表的哈希表项改为指向我们重写的新数据块。
这样导入物零风险，改动面最小。

- mpq.py：MPQ v1 打包/读取（自测 ✓，mpyq 交叉验证 ✓）
- unprot.py：OP 壳提取（✓，14 标准文件 + 块级暴破恢复 17 个未知导入）
- build.py：改造 + 手术式重打包（待写）
- 校验：MPQ 读回断言 + pjass JASS 语法检查 + 1.27 实机开图

## 七、风险与对策

- **改动后地图加载失败**：手术式重打包把未知导入原样保留，风险集中在改过的文件；
  每次构建后跑读回断言 + pjass，再实机验证
- **中文乱码**：wts 用 GBK 写入；地图文件名保持 ASCII
- **FF 脚本巨大（422KB）**：只在头部 CONFIG 区和文件尾追加触发块，不重排原函数
- **平衡性**：回忆技能 CD/伤害全部宏定义，改参数重跑
